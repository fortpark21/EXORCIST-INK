## 3) กติกา shading จากเรฟ (ยึดน้ำหนัก ไม่ยึดพิกเซล)

- แสงหลักทิศ **บน-ซ้าย** ทั้งชุดเฟรม — ห้ามสลับทิศแสงตามทิศเดิน
- ผ้าคลุม: อย่างน้อย **3 ระดับค่า** (เงาพับ / กลาง / รับแสง) ริ้วแขน ชายเสื้อ เอวต้องมีน้ำหนัก ห้ามผ้าเรียบทึบ
- ผมเงิน: เป็นก้อนมิติ ไม่ใช่เส้นฝอยทั้งหัว — มีไฮไลต์บนกระหม่อม + ปอยดำอ่านได้ตอนย่อ 96px
- ขอบนอกใช้เส้นหมึกหนา-บางตาม `ART_BIBLE` ไม่ใช้ outline ดำเท่ากันรอบตัว
- Rim เย็น 1–3 px ตาม bible (`#8C94B8` / `#7762A5`) อย่าล้อมทั้งตัว
- เงาเท้าเบาในช่อง 8 px ล่าง ห้ามเงากิน collider
- ตอนย่อบนไทล์ 64 ยังต้องอ่าน: ผมเงิน / ชุดม่วง / ดาบ / ท่าเท้า

ห้าม: เปลี่ยนเกมเป็น pixel art, cel anime, สัดส่วนจิบิ, ดาบยาวเกินตัว, กล้องหน้าตรงแบบแฟชั่น

## 5) ห้ามรื้อของเดิม

- ปรับจูนจากโครงที่พรทำแล้ว (สัดส่วนนักพรต ผมเงินปอยดำ ชุดม่วงดำ ดาบเล่มเดียว)
- เฟสตรวจ = เกลี่ยแสงเงา ริ้วผ้า มิติผม ตามเรฟ — **ห้ามรีเจนทั้งตัวใหม่แล้วทิ้งโครง**
- เปลี่ยนได้เฉพาะเมื่อโครงผิดกริด (เท้าไม่ตรง 48,88 / หัวกระโดด / กล้องไม่ ¾) — บอกต้นก่อนทิ้งเฟรม
- อัปเดต `ASSET_MANIFEST.md` เมื่อย้ายเข้า runtime และ `GENERATION_PROMPTS.md` เมื่อใช้/ปรับ prompt (พรคนเดียว)
