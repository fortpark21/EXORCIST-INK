| A2 | **แต้มสเตตัส 4/level + โบนัส 1 ทุก 5 เลเวล** | รวม 130 แต้มที่ Lv.32 | ผูกกับ A1 — แก้ตัวใดตัวหนึ่งต้องแก้คู่ |
| A3 | **Level cap = 50** | บรีฟบอก "exp curve ถึงอย่างน้อย Lv.50" ผมตีความว่า 50 เป็น cap ของ Phase 2 | ถ้าตั้งใจให้ไปไกลกว่า 50 ให้บอก ผมจะต่อ tier 51–60 (×2.0), 61–70 (×2.3) |
| A4 | **เวลาเดินข้ามเมือง ~28 วินาที** (แมพ 80×64 tile) | ขนาดแมพผมเดาจาก "เมืองที่มีร้าน + ที่พัก + ลาน + ประตู" | ถ้าอยากให้เมืองเล็กลงเดินไว ลดเป็น 60×48 tile (~21 วินาที) แก้แค่ `maps.json` |

| A6 | **ไม่มีไอเท็มร่วงพื้น — auto-loot เข้ากระเป๋าทันที** · **ล็อกแล้ว** | ตัดงาน pickup entity + loot ownership ซึ่งเป็นปัญหาใหญ่ตอน MP | ปิดแล้วตาม L3 — ของร่วงพื้นไม่ทำใน Phase 1–2 |
| A7 | **Basic attack เป็นคอมโบ 3 step** | บรีฟเขียน "Combo (ถ้ามี)" → ผมใส่ เพราะเกม action top-down ที่ตีท่าเดียวซ้ำ ๆ จะจืดมาก | ถ้าอยากตัดเหลือท่าเดียวให้ใช้แค่ step 1 แล้วลด `comboWindowTicks` เป็น 0 (ตัวเลขอื่นไม่ต้องแก้) |
| A8 | **ปุ่มโจมตี = `J` / `Space`** · กินโพชั่น `Q` · คุย `E` | บรีฟระบุแค่ WASD+ลูกศร | คีย์บอร์ดคงชุดนี้ · ทัชแปลงเป็นธง `InputFrame` ชุดเดียวกัน (`01` §1.4) ไม่ต้องมีสกีมาปุ่มใหม่ |
| A9 | **Monster ช้ากว่าผู้เล่น (145 vs 180 px/s)** | เป็นการตัดสินใจเชิงดีไซน์ที่สำคัญ: ผู้เล่นหนีได้ตลอด → ความตายเป็นความผิดตัวเอง ไม่ใช่เกมโกง | ถ้าอยากให้กดดันกว่านี้ ให้เพิ่ม `speedChase` เป็น 165 (ยังหนีได้แต่ฉิวเฉียด) **ไม่แนะนำให้เกิน 180** |
| A10 | **ตายเสีย exp 3% (Lv.6+ ขึ้นไป) ไม่เสียของ ไม่เสียเงิน** | บรีฟถามว่า "เสีย exp ไหม" แต่ไม่ได้บอกเท่าไหร่ | ปรับ `expPenaltyPercentOfCurrentLevelRequirement` ตัวเดียว · ถ้าอยากไม่มีบทลงโทษเลยตั้ง 0 |
| A11 | **มีระบบ Hit / Flee (หลบของมอน)** | บรีฟให้ DEX ต้องมีผล แต่ไม่ได้บอกว่าอะไร → ผมให้ DEX = ASPD + crit + hit | **คนละเรื่องกับ dodge roll ของผู้เล่น** (E4 ล็อกแล้วว่าไม่มี) · ถ้าไม่ชอบ hit chance ให้ตั้ง `hit.baseHitChance = 1.0` |
| A12 | **Potion = flat + % ของ max** | บรีฟถามว่า "ค่าคงที่หรือ %" → ผมตอบว่า **ทั้งคู่** (120 + 10%) | flat ช่วยช่วงต้น · % ช่วยไม่ให้ไร้ค่าช่วงปลาย |
| A13 | **Auto Potion trigger ที่ 35% HP** | บรีฟถาม "ที่กี่ %" แต่ไม่ได้บอก | 35% คือ 2 ครั้งของ Demon Boar charge ที่ Lv.6 — รอดชัวร์ |
| A14 | **Idle animation 2 เฟรม ไม่ใช่ 1** | บรีฟบอก "idle 8 ทิศ" เฉย ๆ · ตัวนิ่งสนิทดูเหมือนเกมค้าง | ผมใส่ `supportsSingleFrameFallback: true` ไว้ ถ้าพอร์นส่ง 1 เฟรมมาก็ยังรันได้ |
| A15 | **Hit stop เป็น render-only** | ถ้าหยุด Sim จะพัง determinism และทำ MP ไม่ได้เลย | **ข้อนี้ผมขอไม่ให้เปลี่ยน** — เป็นเรื่องสถาปัตยกรรมไม่ใช่ดีไซน์ |
| A16 | **ชื่อเมือง "เมืองหมึกเงิน" / ทุ่ง "ทุ่งหมอกหมึก"** · ชื่อไอเท็ม/ท่าโจมตีไทยทั้งหมด | บรีฟไม่ได้ให้ชื่อสถานที่ | ตั้งใหม่ได้อิสระ แก้แค่ `displayName` ไม่กระทบโค้ด (ขอให้ `id` คงเดิม) |
| A17 | **ออก-เข้าแมพ = มอน reset หมด** | Offline-first ไม่ต้อง persist monster state | ผู้เล่นใช้เป็นช่องโกงรีเซ็ตมอนได้ ผมประเมินว่า "เสียเวลากว่าเดินไปตัวถัดไป" จึงไม่คุ้มโกง |

| B9 | **Save / Autosave trigger** | ผมระบุแค่ "autosave หลัง respawn" · นัทมี `localSave.ts` อยู่แล้ว แต่ต้องตัดสินใจว่าเซฟตอนไหนอีก (เปลี่ยนแมพ? level up? ทุก 60 วินาที?) |

## C. ไอเดียที่เลื่อนไป Phase 3+ (จดไว้ ไม่ได้ออกแบบ)

### Phase 3 — เมือง & เศรษฐกิจ
- **Shop / Blacksmith** เต็มรูปแบบ (`ShopDef` / `UpgradeDef` ของนัทรออยู่แล้ว)
- **ตีบวก +1…+10**: สูตร `refineStep` ผมเตรียมไว้แล้ว เหลือ success rate + เงื่อนไขพัง/ไม่พัง
- **Equipment drop + rarity tier** (ธรรมดา/ดี/หายาก/เทพ) พร้อม random affix
- **สกิลที่กิน MP** 4–6 ท่าของ Sword Exorcist + skill tree (skill point 34 แต้มที่ Lv.32 รออยู่)
- **ระบบเควสต์เชิงลึก** + เนื้อเรื่อง
- **Respec / ล้างสเตตัส** (ดู B5)
- โพชั่นขนาดกลาง/ใหญ่ (flat 350 + 12%, flat 800 + 15%)
- Durability / ค่าซ่อม — **เสนอว่าอย่าทำ** ไม่เข้ากับฟีล action

### Phase 3–4 — เนื้อหา & ศัตรู
- **Ink Wisp** (ตามบรีฟ) — มอนบินได้ ranged ต้องมี projectile system
- มอนเพิ่มอีก 4–6 ตัวครอบ Lv.10–50 (แก้ B1)
- **Elite / Champion mob** (ตัวใหญ่ HP ×4 drop ดีกว่า) — ของถูกมาก คุ้มมาก ใช้ asset เดิม
- Status effect: ติดพิษ / เลือดไหล / ชา (หมึกเกาะ) — ต้องออกแบบ stack/duration ให้ deterministic
- **Boss**, **Dungeon** — ตามบรีฟคือ Phase 3-4
- **Cultivation** (ระบบบำเพ็ญ) — ตามบรีฟ
- Day/night cycle + โคมไฟติดตอนกลางคืน (ผมใส่ `lightRadiusPx` ไว้ใน `lantern_post` แล้ว)

### Phase 4–5 — Multiplayer
- Netcode (server-tick + client prediction + rollback) — **ข้อควรทำตั้งแต่วันนี้อยู่ใน `02-combat.md §11`**
- Monster ownership / exp sharing — ผมใส่ `damageContributors` เป็นช่องว่างไว้แล้ว
- Party / Bot — ตามบรีฟ
- Loot ownership (ถ้าตัดสินใจทำของร่วงพื้นทีหลัง)
- Trade / ตลาดผู้เล่น

### อาชีพอื่น (ยังล็อก)
- Dual Blades / Bow / Magic — ผมเตรียม `matkFlat` ใน INT และ `mdef` ใน monster ไว้ให้แล้ว
  เวลาปลดล็อกจะได้ไม่ต้องแก้ data schema
